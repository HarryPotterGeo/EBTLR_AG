# EBTLR_AG
"Enhanced Bipartite Tensor Low-rank Representation and Adaptive Graph Learning for Multi-view Clustering" 



Some tips to use this package code:
1. Open Run.m to run EBTLR_AG.
2. You can replace the dataset in the experiment as you want.



Recommended parameters:
  1. Prokaryotic：  rate = 0.135, alpha = 1.7;
  2. Pascals：      rate = 0.034, alpha = 2;
  3. UCI：          rate = 0.017, alpha =  3.5;
  4. HW1256：       rate = 0.026, alpha = 3.5;
  5. Mnist4:        rate = 0.005, alpha = 3.8;
  6. Hdigit:        rate = 0.0039 ; alpha = 2.1;
